# Raj Dental Clinic & Implant Centre Website

A modern single-page dental clinic website built with:

- React + Vite
- Tailwind CSS
- Node.js + Express

## Project structure

- `client/` → React frontend
- `server/` → Express backend APIs

## Run locally

```bash
npm install
npm run dev:client
npm run dev:server
```

Frontend runs at `http://localhost:5173` and backend runs at `http://localhost:4000`.
